# وثيقة المواصفات التقنية: تطبيق القياس الذكي (Smart Tailor)

**الإصدار:** 2.0 (Lightweight Client Architecture)  
**التاريخ:** 5 ديسمبر 2025  
**الحالة:** مسودة نهائية للتنفيذ

---

## 1. ملخص تنفيذي (Executive Summary)

يهدف هذا المشروع لبناء تطبيق ذكي لأخذ مقاسات الجسم بغرض تفصيل الملابس بدقة عالية، مع التركيز على:
- **خصوصية المستخدم:** عدم إرسال صور
- **خفة التطبيق:** حذف المكتبات الثقيلة مثل OpenCV
- **دقة القياسات:** دمج خوارزميات SMPL مع معايرة البطاقة البنكية

تعتمد المعمارية الجديدة على مبدأ **"العميل الخفيف والخادم الذكي"** (Light Client, Heavy Server)، حيث يقوم الهاتف بجمع البيانات الأولية فقط، بينما يتولى الخادم العمليات الحسابية والهندسية المعقدة.

## 2. المعمارية العامة للنظام (System Architecture)

### 2.1 تطبيق الهاتف (Flutter Client) - "المستشعر"

| الخاصية | الوصف |
|---------|-------|
| **المسؤولية** | التقاط الفيديو، استخراج البيانات الوصفية (Metadata)، التوجيه الصوتي للمستخدم |
| **السمات** | لا يقوم بمعالجة الصور المعقدة، لا يحتوي على OpenCV، يرسل ملفات نصية (JSON) صغيرة الحجم |

### 2.2 الخادم الخلفي (Python Backend) - "المعالج"

| الخاصية | الوصف |
|---------|-------|
| **المسؤولية** | استلام البيانات، تصحيح المنظور هندسياً، بناء النموذج ثلاثي الأبعاد (3D Reconstruction)، واستخراج القياسات بالسنتيمتر |
| **التقنيات** | GPU Processing, SMPL-X, PyTorch |

## 3. المواصفات التقنية لتطبيق الهاتف (Mobile App Specifications)

### 3.1 حزمة التكنولوجيا (Tech Stack)

| المكون | التقنية |
|--------|---------|
| **الإطار** | Flutter (Dart) |
| **المكتبات الأساسية** | |
| - التحكم في الكاميرا | `camera` |
| - استخراج الهيكل العظمي | `mediapipe_flutter` |
| - تشغيل نموذج YOLOv8 | `onnxruntime` |

> ⚠️ **ملاحظة:** تم إزالة `opencv_dart` لتقليل الحجم وتحسين الأداء.

### 3.2 خط أنابيب المعالجة (Processing Pipeline) داخل الهاتف

يعمل التطبيق على تحليل كل إطار (Frame) كالتالي:

#### 3.2.1 كشف البطاقة (Card Detection)

- **التقنية:** نموذج YOLOv8 Nano (نسخة Int8 الخفيفة)
- **المخرج:** إحداثيات الزوايا الأربع للبطاقة (x, y) فقط
- **ملاحظة:** يتم إرسالها كما هي دون تصحيح

#### 3.2.2 تحليل الجسم (Pose & Segmentation)

- **التقنية:** نموذج MediaPipe Pose
- **المخرج 1:** نقاط الهيكل العظمي (33 Landmark) لتحديد وضعية الوقوف
- **المخرج 2:** قناع الفصل (Segmentation Mask) - صورة ثنائية (Binary) تفصل الجسم عن الخلفية

#### 3.2.3 استخراج حدود الجسم (Silhouette Extraction) - بديل الصور

بما أننا لا نرسل الصور، يجب تحويل "قناع الفصل" إلى بيانات هندسية:

- **الخوارزمية (Dart):** تطبيق خوارزمية تتبع بسيطة (مثل Marching Squares المبسطة) على القناع لاستخراج النقاط الخارجية المحيطة بالجسم
- **الضغط:** تقليل عدد النقاط (Downsampling) (نقطة لكل 10-20 بكسل) لإنتاج مضلع (Polygon) خفيف الحجم يمثل شكل الجسم وامتلاءه

## 4. بروتوكول البيانات (API Contract)

يتم تجميع البيانات من **4 زوايا تصوير** (أمام، خلف، يمين، يسار) في ملف JSON واحد وإرساله للسيرفر.

## 5. المواصفات التقنية للخادم (Backend Specifications)

### 5.1 حزمة التكنولوجيا

| المكون | التقنية |
|--------|---------|
| **اللغة** | Python 3.9+ |
| **الإطار** | FastAPI (للسرعة العالية) |
| **مكتبات المعالجة** | OpenCV (للعمليات الهندسية)، PyTorch (للذكاء الاصطناعي)، Trimesh (للهندسة ثلاثية الأبعاد) |
| **النماذج الأساسية** | SMPL-X / SHAPY / ViTPose (اختياري للدقة القصوى) |

### 5.2 خوارزمية المعالجة المركزية (Core Algorithm)

#### 5.2.1 المعايرة الهندسية (Calibration)

1. استلام `corners` البطاقة من JSON
2. تطبيق `cv2.getPerspectiveTransform` لحساب مقياس الرسم (Pixels per CM) بدقة

#### 5.2.2 إعادة بناء القناع (Mask Reconstruction)

- رسم مضلع `body_silhouette_polygon` على خلفية سوداء لاستعادة "شكل الجسم" (Binary Mask) الذي يراه النموذج

#### 5.2.3 تحسين النموذج (Model Optimization)

- استخدام خوارزمية **SMPLify-X Multiview**
- **الهدف:** إيجاد مجسم ثلاثي الأبعاد (Mesh) واحد يحقق شرطين:
  1. مفاصله تطابق `pose_landmarks`
  2. ظله (Projected Silhouette) يطابق القناع المعاد بناؤه (لضمان دقة الوزن والامتلاء)

#### 5.2.4 القياس الافتراضي (Virtual Measuring)

1. تقطيع المجسم (Slicing) عند نقاط تشريحية محددة (الخصر، الصدر، الورك)
2. حساب المحيط باستخدام مكتبة **Trimesh** وضرب الناتج في معامل المعايرة المستخرج من البطاقة

## 6. رحلة المستخدم (User Experience Flow)

### 6.1 الإعداد
يطلب التطبيق من المستخدم تجهيز بطاقة بحجم قياسي وارتداء ملابس ضيقة.

### 6.2 التوجيه التفاعلي
- يستخدم التطبيق الـ **TTS (Text-to-Speech)** لتوجيه المستخدم
- أمثلة: "ابتعد قليلاً"، "البطاقة غير ظاهرة"، "ثبت مكانك"
- بمجرد تحقق الشروط (ظهور كامل للجسم + ظهور البطاقة)، **يلتقط التطبيق البيانات تلقائياً** دون ضغط زر

### 6.3 الدوران
يطلب التطبيق من المستخدم الدوران لليمين، ثم الخلف، ثم اليسار.

### 6.4 الإرسال
تظهر شاشة تحميل بسيطة (حجم البيانات صغير جداً < 50KB).

### 6.5 النتيجة
عرض المقاسات النهائية مع إمكانية تعديلها يدوياً إذا لزم الأمر.
